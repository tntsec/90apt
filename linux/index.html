DNS 使用方法（以安波福为例）

按 0 → 4 顺序操作即可，车机网络与第二部手机需按步骤准备。

  1. 安波福安装调试模式。车机使用移动数据，打开「智能手册」正确选择，更新一次数据；然后关闭移动网络，并给予智能手册存储权限。
  2. 准备一个 Wi-Fi 或手机热点，提供一个稳定的 WIFI 网络，注意使用 IPv4，不要使用 IPv6。
  3. 准备第二部手机，第二部需要连接上面的 Wi-Fi 并且能够同时共享热点。
  4. 第二部手机的 Wi-Fi 修改 DNS 域名为免费 DNS 的 IP。
  5. 车辆连接第二部手机的热点，点击「智能手册」，即可安装工装工程模式，使用 ADB。

# 壁纸裁剪器

可在 GitHub Pages 运行的静态壁纸裁剪工具。

## 功能

- 上传 JPG / PNG / WEBP，或把图片拖进预览区
- 预设：720p、1080p、2K、4K、1920×720、1:1 1080
- 自定义宽高
- 拖动裁剪框、四角缩放（保持目标比例）
- 触屏友好（Pointer Events）
- 保存下载为 PNG 或 JPEG

## 本地打开

直接用浏览器打开 `index.html`，或起一个静态服务。

## 发布到 GitHub Pages

1. 把本仓库推到 GitHub
2. 仓库 Settings → Pages
3. Source 选 `Deploy from a branch`
4. Branch 选 `main` / `root`
5. 访问 `https://<用户名>.github.io/<仓库名>/`
